# Cameron Generation — Cameron Parish air permits

**Verified notice, not an issued permit.** On October 15, 2026, LDEQ received air-permit applications for *Cameron Campus Data Center No. 1*, applicant Cameron Generation, LLC. LDEQ determined the application was administratively complete. The determination does not authorize construction or operation.

## Open original public sources

- [LDEQ notice, published November 1, 2026 by the Cameron Parish Pilot](https://cameronpilot.com/o-52-2/)
- [LDEQ EDMS public-records portal](https://www.deq.louisiana.gov/page/edms) — search by **Agency Interest 241614** for the actual application records and technical attachments
- [LDEQ public notices](https://www.deq.louisiana.gov/public-notices)
- [Venture Global SEC credit agreement listing Cameron Generation, LLC](https://www.sec.gov/Archives/edgar/data/2007855/000200785526000013/exhibit10104-10k2025.htm)
